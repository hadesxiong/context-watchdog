## 0. 环境准备

```bash
npm install
npm run build           # Chrome：chrome://extensions 加载 dist/
npm run build:firefox   # Firefox：about:debugging → 加载临时附加组件 → dist-firefox/manifest.json
```

- 实机验证一律用构建产物，**不要用 `npm dev`**；
- 观察点：侧栏控制台与 service worker 控制台的 `[ContextWatchdog]` 日志；
- 每轮回归先跑 `npm run typecheck && npm test`（期望见附录 A）。

### 检验样例文本

> **复制注意**：
> 1. 下列样例一律**整段复制代码块内容**——不要带反引号/前后空格/表格符号，行首「顶格」。
>    行首任何不可见字符都会让 env 规则（`^` 锚点）失配，造成 `KEY=值` 漏检；
> 2. 除注明「单独检测」外，样例**一次贴入同一文本框、一次检测**——占位符序号
>    （如 `<<手机号:2>>`）按单次检测计数，分次贴入序号会重置；
> 3. 样例 A/B/C/E 在「不限」档、AI 开/关均可测（正则档行为与 AI 无关）；
>    样例 D 必须 AI 就绪。

**样例 A**——密钥类检测（4 行，真换行）：

```

REDIS_URL=redis://cache01:6379/0
```

**样例 B**——PII 类检测（单行；卡号为 Luhn 合法校验位）：


**样例 C**——弱值/无敏感不误报（5 行，**真换行**——不要复制成字面 `\n` 单行）：

**样例 D**——AI 增强推理（姓名/地址自由文本，需 AI 就绪）：

## TC 索引

> 编号在仓内可解析（spec、CHANGELOG、源码注释均引用）；完整步骤与逐条预期见作者自存归档。

### TC-01 安装与加载
- **TC-01-1** Chrome 加载 —— 无任何警告加载 `dist/`，图标正常，点图标开侧栏。
- **TC-01-2** 权限提示 —— 授权弹窗如实描述目标站点；拒绝则站点不添加、有错误提示。
- **TC-01-3** Firefox 加载 —— 无未知键警告，打开同一面板，CSP 无报错。

### TC-02 正则档检测（AI 关闭）
- **TC-02-1** 密钥类 —— 仅点「检测」出结果；口令与命令行口令检出且 span 只含本体，散文谓词零误报。
- **TC-02-2** PII 类 —— 手机/身份证/卡号（Luhn）/邮箱/IP/车牌检出；姓名住址不属正则档。
- **TC-02-3** 高熵与灵敏度 —— 标准档检出、strict 档收紧、档案默认 keep 不替换。
- **TC-02-4** 弱值不误报 —— 空值、纯数字、过短、弱密码零检出。
- **TC-02-5** 重复值与同占位符 —— 3 处全检出并共享同一占位符。
- **TC-02-6** 重叠仲裁 —— 凭据类优先，区间互不切坏。
- **TC-02-7** 短密钥族 —— 有前缀即证据；无前缀与残缺前缀不检出。

### TC-03 检出交互
- **TC-03-1** 空结果 —— 显示绿色对勾「未检测到需要替换的内容」，整列不消失。
- **TC-03-2** 置信度徽章 —— 高红、中黄、低绿，颜色可辨。
- **TC-03-3** 单条保留/恢复 —— 即时生效并反映到最终复制结果。
- **TC-03-4** 复制 —— 整体为替换后全文（保留项原文），单条为该条结果。
- **TC-03-5** 默认策略 keep —— 邮箱检出但默认保留原文。

### TC-04 档案管理
- **TC-04-1** 档案下拉 —— 两行菜单项、内置档无齿轮、新建自动激活并打开设置。
- **TC-04-2** 编辑齿轮 —— 关菜单、激活、开弹窗三步一次完成不丢点击。
- **TC-04-3** 设置弹窗结构 —— 头部固定正文滚动、底部操作区 sticky、无「取消」且丢弃草稿。
- **TC-04-4** 表单控件 —— 即时生效、保存后重开状态持久。
- **TC-04-5** 白名单 —— 该值（含所有重复出现）不再检出，删除后恢复。
- **TC-04-6** 删除档案 —— 删除后回退内置档、下拉项消失、防重复点。

### TC-05 自定义正则
- **TC-05-1** 添加与命中 —— 自定义规则命中并按所选类型展示，可停用。
- **TC-05-2** ReDoS 拒绝 —— 嵌套量词与超长模式拒绝保存。
- **TC-05-3** 导入导出 —— 合法 JSON 全量往返恢复；坏 JSON 报错不崩溃。

### TC-06 AI 增强全状态路径
- **TC-06-1** 首启引导与开关 —— 正则恒开禁改、AI 可开关且持久化。
- **TC-06-2** 首次下载 —— 真实进度条 0→100% 后就绪。
- **TC-06-3** 缓存命中静默 —— 二次开启零提示直接就绪。
- **TC-06-4** 断点续传 / 多窗口（可选深测）—— 断点续传不归零、多窗全程仅一次下载。
- **TC-06-5** 就绪推理 —— 真实模型日志出现；样例 D 在正则之外补出 `<<姓名>>`/`<<地址>>`（多语言模型），其余幻觉仍由形状门禁拦截。
- **TC-06-6** 失败路径与重试 —— 断网不永久卡 loading，恢复后可重试。
- **TC-06-7** 关闭复位 —— 回退纯正则结果。
- **TC-06-8** 离线推理 —— 断网照常推理，零 CDN 请求。
- **TC-06-9** 版本探测不误判重下 —— 二次打开绝不重下 183MB，探测真实执行。

### TC-07 粘贴自动拦截
- **TC-07-1** 授权添加 —— 条目原样显示；带路径只在路径下生效，裸域名覆盖子域。
- **TC-07-2** 就地替换 —— 粘入即替换不阻塞输入；档案判定保留的项保持原文。
- **TC-07-3** 守卫 —— password 框、超长文本、输入已变三项均不误改。
- **TC-07-4** 移除站点 —— 移除后粘贴不再替换、权限一并撤销。
- **TC-07-5** 未授权站点零接触 —— 零注入、零监听。
- **TC-07-6** contenteditable 富文本 —— 占位符插入原光标处，异常时绝不吞粘贴。
- **TC-07-7** 「已脱敏 N 处」轻提示 —— 命中出现、约 2 秒消失、不堆叠。
- **TC-07-8** 站点挂件与逐站 AI 开关 —— 按钮文案与实际形态一致（含 Firefox 分支），外部关闭后恢复可点、页面重渲染自动重挂。
- **TC-07-9** 粘贴链路的 AI 二次升级 —— 正则立即落地、AI 增量二次替换；任何失败保正则不回退原文。

### TC-08 UI 细节（判据已随㉕移出，作者自存）

- **TC-09-2** 超长文本 —— 5 万字符检测不卡死；粘贴拦截超 20000 字符直接放行。

## 附录 A：自动化测试基线

- 运行：`npm test`（vitest，期望 **420 passed / 33 文件**）；`npm run typecheck` 0 错误。
- 浏览器探针：`npm run probe:layout`（侧栏布局 85 项，无头 Chrome + CDP）、
  `npm run probe:widget`（授权站点挂件 / iframe 不挂 / 未授权零注入 / 不影响页面布局 /
  收起态 44×44 / 12px 圆角矩形 / mark 跟随明暗主题换色 / 暗色下面板有边框 /
  「在侧边栏中打开」真的打开面板并切到已打开态 / 侧栏开/关的实时推送使按钮双向即时翻转 /
  展开态轮询一个周期后不把「已打开」翻回 / 页面重载后挂件初始即「已打开」禁用态 /
  删除后自动重挂，共 20 项，需要 Chrome for Testing 或 Chromium——正式版 Chrome 与
  新版 Edge 会忽略 `--load-extension`，Windows 上用 `CHROME_PATH` 指向 Chromium
  （如 `%LOCALAPPDATA%\ms-playwright\chromium-*\chrome-win64\chrome.exe`））。
- 覆盖分布：
  - `tests/golden/`（4 文件）：内置三档档案 + 白名单的端到端金样例断言；
  - `tests/unit/`（26 文件）：正则规则/值过滤、自然语言口令（构造串）、命令行口令
    （构造串）、短密钥族（构造串）、自定义规则 ReDoS、
    管线配置（正则恒开）、store 状态机、模型下载（续传/退避/看门狗/缓存/锁/版本探测）、
    宿主状态归并、有效 AI 判定（全局 × 本站 × 宿主）、粘贴改写与 AI 升级守卫、

  - `tests/perf/longtext.test.ts`：长文本性能护栏；
  - `tests/regression/`（2 文件）：历史缺陷回归 + CJK 边界。
